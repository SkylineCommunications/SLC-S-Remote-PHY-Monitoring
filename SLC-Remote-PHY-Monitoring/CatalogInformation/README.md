# Remote PHY Monitoring

## About

The **Remote PHY Monitoring** package empowers you to effortlessly access and consolidate data from one or more remote PHY devices. It contains two low-code apps and a **Vecima RPM** connector.

Currently, Vecima RPM is the only device supported by this solution.

![RemotePhyMonitoringOverview](./Images/RemotePhyMonitoringOverview.png)

## Key Features

The single entry point provided for your entire installed base of remote PHY nodes eliminates the need to switch between the interfaces of the different RPM elements.
